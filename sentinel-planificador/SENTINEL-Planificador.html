Tu proyecto, en una carpeta

1. Mantén tu seguimiento

Abre SENTINEL-Planificador.html con doble clic. Los cambios se guardan en este navegador cuando su almacenamiento está disponible. No se envían a ningún servidor.

Exporta JSON al terminar. Mover el HTML, cambiar de navegador o borrar sus datos puede dejarte sin el guardado local.

2. Retoma en otro chat

Usa Llevar a otro chat para descargar contexto TXT. En una tarea puedes copiar un encargo que incluye el agente, decisiones y dependencias. Adjunta también el JSON para conservar el estado completo.

3. GitHub y publicación

El paquete incluye fuente separada y un HTML portable. Puedes subirlos a GitHub. Con GitHub Pages habilitado, publica la carpeta raíz que contiene index.html.

GitHub no recibe automáticamente tus cambios de tareas. Exporta y conserva el JSON. No incluyas información personal o evaluaciones en un repositorio público.

4. Arquitectura modular

Este tablero separa datos iniciales, reglas, almacenamiento, UI y estilos. El HTML portable se genera desde esos módulos.

La futura app también separará pantallas, dominio, datos, permisos, historial, reportes y respaldo; falta aprobar sus contratos.

5. Cerrar una tarea

Abre una tarea, revisa criterios y dependencias. Para marcarla Completada debes registrar evidencia y completar sus dependencias. Una fecha queda registrada.

Las tareas opcionales no cuentan en el avance general hasta que decidas incorporarlas.

6. Respaldo del tablero

Importar reemplaza el estado completo después de tu confirmación. Primero se descarga una copia del estado actual. No importa cualquier JSON ni ejecuta su contenido.
